## Описание проекта
Приложение разработано в рамках лабораторной работы №6 по курсу мобильной разработки для ОС Android.

Цель работы — практическое освоение воспроизведения локальных аудио- и видеоресурсов, управление громкостью медиапотока и корректная обработка жизненного цикла мультимедийных компонентов без утечек памяти.

### Реализованный функционал:
1. **Подготовка медиаресурсов (`res/raw`)**:
   - `sample_audio.mp3` — аудиофайл формата MP3.
   - `sample_video.mp4` — видеофайл формата MP4 (H.264 / AAC).

2. **Аудиоплеер (`AudioActivity`, `MediaPlayer`)**:
   - Управление воспроизведением: кнопки «Play», «Pause», «Stop».
   - Регулировка громкости через `AudioManager` строго для медиапотока (`AudioManager.STREAM_MUSIC`).
   - Отображение текущего статуса («Воспроизводится», «На паузе», «Остановлено», «Завершено»).
   - Обработка ошибок через `setOnErrorListener` без краша приложения.
   - Освобождение ресурсов в `onDestroy()` (`mediaPlayer.release()`).

3. **Видеоплеер (`VideoActivity`, `VideoView`)**:
   - Локальный источник через URI вида `android.resource://[package]/[raw_id]`.
   - Интеграция стандартного контроллера `MediaController` (перемотка, пауза, воспроизведение).
   - Индикатор загрузки `ProgressBar` во время подготовки видео (`setOnPreparedListener`).
   - Безопасная остановка в жизненном цикле (`onPause()` и `videoView.stopPlayback()` в `onDestroy()`).

## Сборка и запуск
- Минимальная версия Android SDK: API 24 (Android 7.0)
- Целевая версия Android SDK: API 37
- Язык разработки: Kotlin
- Готовый установочный файл приложения: `app-debug.apk` в корне репозитория.
